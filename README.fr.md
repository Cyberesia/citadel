# Citadel

> **Brouillon** — version française à compléter avant l’ouverture du dépôt.  
> Voir [README.md](./README.md) (anglais) pour la documentation complète.

Citadel est votre centre de commande macOS pour le contrôle réseau et l’IA locale.

**Fortress** surveille chaque connexion. **Keep** exécute vos agents derrière les murs.

Vous gardez le contrôle — sur votre Mac, à vos conditions.
