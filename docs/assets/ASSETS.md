## Tips

- Capture on macOS 14+ with dark mode and default Prism theme.
- Use `.webm` for GitHub (smaller than `.mp4`); keep under ~5 MB when possible.
- Upload to GitHub Releases or `user-attachments` and update URLs in `README.md` if you prefer hosted assets over repo paths.
